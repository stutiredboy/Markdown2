# 实体键盘复核

请用候选 Markdown2 开发包和测试文档。建议先用「简体中文」完成一轮，
再在「设置 → 通用 → 语言」切到 English，重新打开英文测试副本。切换输入法时，
请选择 macOS 自带的「简体拼音」。不要用自己的文档测试异常保存。

| 操作 | 当场核对 |
| --- | --- |
| 按 ⌘O 打开测试文档，输入一小段文字，再按 ⌘Z。 | 标题先出现星号，撤销后源码恢复。激活 VoiceOver 后听到「Markdown 源码」或 “Markdown Source”。 |
| 在末尾的空列表项后加空格，保存，切到简体拼音，键入 wubi。慢慢按两次 Return，再键入 nihao，按空格提交。 | 组字时标题仍干净；第一次 Return 只提交 wubi，第二次才续写列表。选出的「你好」可用一次撤销移除。再试一次用 Escape 取消未提交的候选。 |
| 在空行按 ⌥⌘T，用 Tab／Shift+Tab 遍历。用「格式 → 表格操作」插入一行，再撤销。 | 仅切换单元格不会修改源码。插入行只需要一次撤销。 |
| 在「编辑」中分别使用粘贴为纯文本、Markdown、表格。 | 粘贴并撤销后逐次比较源码，尤其是 Markdown 标记、富文本粗体和 TSV 的中文单元格。建议用[验收方案中的三个样例](PLAN.md#run-in-each-app-language)。 |
| 按 ⌥⌘F 查找 needle；Tab 到「替换为」，再到「替换」或「全部替换」，用空格激活。 | 两个字段分别有独立名称。尚有匹配时可连续按空格做单次替换；用完匹配后按 Escape 能回到源码。全部替换可一次撤销。 |
| 按 ⌃⌘3 切到双栏。从源码用 Control+Shift+Tab 向后找「为本文档允许…」，按空格。 | VoiceOver 能读出确认窗。初始焦点在「取消」；Escape 返回；再打开，Tab 到「允许远程图片」并按空格。允许后焦点落在「阻止远程图片」，再按空格即撤销。若要校验真实流量，使用方案中的本地服务器及带端口的副本。 |
| 按 ⌘S 保存，分别从「文件 → 导出到」选择 HTML、PDF。 | 保存后标题清除星号。导出可用键盘提交，文件可打开，正文完整，离线 HTML 不加载远程图片。 |
| 用独立文件触发只读保存和外部修改冲突。 | 按[异常演练步骤](PLAN.md#save-failure-and-conflict)执行。听 VoiceOver 是否读出原因，核对错误时原磁盘内容、未保存标记和关闭后的焦点。冲突分别试「从磁盘重新载入」和「保留我的版本」。 |

如需从键盘访问菜单栏，可按 Control+F2（部分键盘需要加 Fn），
再用方向键和 Return。VoiceOver 通常用 ⌘F5 开关，VO+M 进入菜单栏，
VO+Space 激活控件。复核后请记录语言、通过项、卡住时所在控件及按键顺序；
对播报问题请再记录实际听到的句子。
