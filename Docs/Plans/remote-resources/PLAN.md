# Remote resources: policy and acceptance contract

Baseline: main `8f8df8a8d24ba65ec667293bb4e9d2ed6d3c1cde` (PR57 merged). Status: contract frozen; implementation and independent acceptance pending.

## Priorities and behavior

1. **Default deny.** Opening/editing/reloading a document must not automatically fetch document-authored HTTP(S) subresources in preview, PDF or Print. Preserve exact local-image access, trusted bundled scripts/styles/fonts, math and diagrams. A blocked image is explained as blocked, not mistaken for a missing file or generic network failure. Ordinary user-activated safe links still open externally.
2. **Explicit, revocable document-session permission.** A localized accessible control may allow HTTP(S) image-class subresources for this document in this session. Explain that requests reveal network/request information. This includes CSS/SVG/diagram image requests, not only Markdown image syntax. It never grants network scripts, stylesheets, fonts, frames, media, fetch/XHR or automatic navigation. No global preference, source/front-matter directive, persisted trust, remembered domain allowlist or preview permission in ExportProfile. A different/opened/reloaded/recovered document starts blocked; normal edits and rename of the same document may keep the current grant. Another window never inherits it.
3. **Revocation and isolation.** Policy and document identity/epoch are captured explicitly. A policy-only change must replace the page/security context and invalidate pending full/live rendering work even when body text is identical. Stop obsolete page/export loads; stale work must not initiate new remote loads or publish a canceled export. Already transmitted requests cannot be recalled. Use ephemeral WebKit data stores and no-referrer page policy; do not share browser login/cookie/cache state between documents or exports. This is not a LAN/IP allowlist, DNS-rebinding firewall, or a claim of zero OS network traffic.
4. **Native exports.** PDF/Print explicitly capture the document policy; granting preview images is also granting image loads for a user-invoked PDF/Print operation. Existing 30-second whole-export bound remains. Do not silently report a successful artifact while known authorized image loads are still unresolved: settle supported image/layout work or fail clearly at the existing deadline, with no partial result. Revoke/replace/close invalidates pending operations. Printing tests create the same temporary PDF without sending a physical print job.
5. **Portable HTML stays offline.** HTML never inherits the session network grant. Only validated embedded image data and trusted bundled inline assets may load. Remote images and local images that cannot be embedded become inert, readable placeholders with an accurate export notice; no active remote/file/relative resource reference may survive in the supported produced page. Existing data images and SVG nested resource paths are included in validation. Ordinary user-clicked hyperlinks are retained. Reopening the actual exported file must not initiate resource requests; CSP must precede governed content and forbid external resources.
6. **External formats have an explicit narrower boundary.** DOCX/EPUB conversion and Pandoc version probes run with network denied for the process and its children. A fixed local mechanism must be verified with positive/negative network controls; missing/failed confinement fails closed, never silently invokes unrestricted Pandoc. Preserve local-image/citation and old-reader compatibility where supported. Do not present these outputs as guaranteed offline documents: independent Word/EPUB readers are outside the app policy, and this batch does not certify every archive relationship/SVG/CSS resource in those formats. Clearly communicate this distinction; recommend HTML/PDF for controlled offline sharing. No remote downloader is introduced.

## Shared API / ownership

- Core public `RemoteResourcePolicy: Sendable, Equatable` with `.blocked` (default) and `.allowRemoteImages`. It is a trusted caller parameter on `MarkdownRenderer.render`, not source metadata or a persisted setting. `RenderAssetMode.inline` alone does not imply remote permission.
- `DocumentRenderSnapshot.remoteResourcePolicy` defaults blocked. Worker normal rendering passes it explicitly; `renderSelfContainedHTML` always forces blocked and the stricter offline artifact boundary.
- Preview receives `remoteResourcePolicy` and a document/policy identity token from DocumentStore. Its loader independently enforces the caller policy, and full/live transitions cannot retain an old head policy. Snapshot/render completion must match current document/policy generation.
- **P package:** core policy/renderer/CSP; MarkdownPreviewView/WebDocumentLoader and their focused tests. Own new loader invalidation/cancel primitives and common WebKit resource boundary. Other packages consume these APIs.
- **E package:** PDFExporter/DocumentPrinter/ExportConfiguration interfaces, SelfContainedHTMLBuilder/image export validation, Pandoc boundary, focused export tests. Coordinate any minimal shared signatures with P/D before editing them.
- **D package:** DocumentStore and DocumentRenderWorker snapshot threading, per-document UX/control/lifecycle, ContentView and localized AppSettings strings. Own shared notices/localization; E sends exact label needs. No persistent grant or ExportProfile field.
- Each package has its own worktree/branch and HANDOFF. Shared ownership is explicit; coordinator integrates reviewed commits serially. Authors do not approve their own packages. Integration review separately checks end-to-end state propagation.

## Acceptance gates

- Independent handwritten/adversarial fixtures cover normal remote images, Markdown/reference/raw HTML, srcset/CSS/SVG/diagram image paths, denied non-image resources, local assets/data, redirects, delayed/failing responses, first/full/incremental load, grant/revoke, document/window changes and stale export snapshots.
- Actual request-counting HTTP servers with unique tokens, no-store responses, gated delays and independent positive controls. A missing image/zero naturalWidth/URLProtocol mock alone is not proof of no request. Separate the tested HTTP/resource boundary from unobserved DNS/speculative/platform traffic. Preserve attack DOM/engine evidence so a removed fixture is not a false negative.
- Test actual PDFExporter/DocumentPrinter and DocumentStore.exportHTML paths and actual artifacts, not only a duplicate test WKWebView. Test reopened HTML, CSS/data/SVG and normal offline math/diagrams; keep existing renderer/formatting/native Undo behavior.
- Test synchronous policy-only changes, same-byte new document, delayed old rendering/exports, two windows, settings isolation, no dirty/save/Undo history from permission UI, English/Chinese labels and native field focus. Clearly separate AppKit/AX automation from physical keyboard/IME/VoiceOver.
- Focused regressions -> independent fixed-SHA review/probes -> serial integration -> full default Swift, separate existing performance/heartbeat lanes, Python, full GUI and unchanged skip audit -> SDK15/development package -> actual macOS15 CI four jobs and independently verified same artifact. Do not relax thresholds/skip lists to obtain green.
- GUI leases are exclusive and performance runs isolated. Snapshot the installed main app/default associations before this batch, and verify unchanged at completion. Clean only this batch's private test app registrations so “Open With” stays clean. No installation, merge, tag or release in this batch. Developer ID/notarization remain deferred.
